Setting up the invitations

Follow the steps in order. Tap Mark done on each one as you go; this page remembers where you were. Whenever you see a Copy button, press it and paste where the step says.

Part A Get the sheet ready 10 min

  1. From your own Google account, open the Google Sheet and share it with info@.

    Click Share (top right), type this email, set it to Editor, click Send.

    info@jupitertexas.com

  2. Log in as info@jupitertexas.com. From here on, everything happens in that account.

    Easiest way: open Chrome, click your profile picture (top right) → Add → sign in as info@jupitertexas.com. A separate window opens just for that account.

    Why: invitations are sent by whichever account sets this up. If you do it from your own account, the emails go out from your address.

  3. In the info@ window, open Gmail, find the "shared with you" email for the sheet and open the sheet.

    Click File → Make a copy. Name it as below, then click Make a copy.

    Jupiter Holiday Party RSVPs

    The copy opens in a new tab. Use only this copy from now on.

Part B Add the code 10 min

  1. In the copied sheet, click Extensions → Apps Script. A new tab opens with a code editor.

    Click Untitled project at the top left and rename it:

    Jupiter RSVP

  2. You'll see a file called Code.gs with a few lines in it. Click inside the code, press Ctrl + A (Mac: Cmd + A) and then Delete, so it's empty.

    Press the button below, then click in the empty editor and paste (Ctrl + V / Cmd + V).

    Code.gs · {{CODE_LINES}} lines
    {{CODE_PREVIEW}}

    Press Ctrl + S (Mac: Cmd + S) to save.

  3. On the left, next to Files, click the + → HTML. Type this name exactly (with a capital D) and press Enter:

    Dashboard

    Delete the few lines it starts with (Ctrl + A, Delete), then paste this:

    Dashboard.html · {{DASH_LINES}} lines
    {{DASH_PREVIEW}}

    Save again (Ctrl + S).

  4. At the top of the editor there's a dropdown next to ▷ Run. Click Code.gs on the left first, then choose setup in that dropdown and click ▷ Run.

    Google asks for permission:

    • Review permissions → pick info@jupitertexas.com
    • If you see "Google hasn't verified this app": click Advanced → Go to Jupiter RSVP (unsafe). It's safe: it's your own code.
    • Click Allow

    Wait until the bottom says Execution completed. Go back to the sheet tab: you'll now see two tabs at the bottom, Guests and Settings.

Part C Create the two links 5 min

  1. Link 1: the RSVP link (public). In Apps Script, click the blue Deploy button (top right) → New deployment.

    • Click the ⚙ gear next to "Select type" → Web app
    • Description: RSVP
    • Execute as: Me (info@jupitertexas.com)
    • Who has access: Anyone
    • Click Deploy (click Authorize access and Allow again if asked)

    Under Web app, click Copy. Go to the sheet → Settings tab → click cell B2 (yellow, next to "API link") → paste.

    No "Anyone" option? Jupiter's Google admin has turned it off. Send them the message in the "If something goes wrong" section at the bottom.

  2. Link 2: your dashboard (private). Click Deploy → New deployment again.

    • ⚙ gear → Web app
    • Description: Dashboard
    • Execute as: Me
    • Who has access: Only myself
    • Deploy

    Copy this Web app link, paste it into a new Chrome tab (in the info@ window) and press Enter. That's your dashboard. Bookmark it (Ctrl + D / Cmd + D).

Part D Put the RSVP page online 5 min

  1. Download jupiter-rsvp-page.zip (the file Claude sent you in the chat) to your computer.

    Double-click it to unzip. On Windows: right-click → Extract All. You now have a folder called jupiter-rsvp-page.

  2. Go to Netlify's sign-up page and click Sign up with Google. Use info@jupitertexas.com so Jupiter owns it. It's free.

    https://app.netlify.com/signup

    If it asks questions about your team or project, pick anything and skip ahead.

  3. Open the drop page and drag the jupiter-rsvp-page folder onto the box in the middle.

    https://app.netlify.com/drop

    After a few seconds you get a link like https://random-words-123.netlify.app.

  4. Give it a proper name, since investors will briefly see it: Site configuration → Change site name → paste the name below → Save.

    jupitertexas-rsvp

    If that name is taken, try jupitertexas-events.

  5. Copy the site's link (for example https://jupitertexas-rsvp.netlify.app). In the sheet's Settings tab, paste it into cell B3.

    Open the link once in your browser: you should see the Holiday Party poster.

Part E Test it on yourself 10 min

  1. Open your dashboard bookmark. Click Send invitations → Send test to me.

    Check info@'s inbox. Open the test email and tap Yes, I'll be there. A page saying "You're in, Test." should open. The test saves nothing, so tap all the buttons freely.

  2. Real test. In the sheet's Guests tab, on row 2, type your own name, your personal email (not info@), and 0 as the phase.

    Refresh the dashboard → Send invitations → choose Phase 0 → Send 1 invitation.

  3. On your phone, open the email. Check that:

    • It's in your main inbox, not Spam or Promotions
    • Tapping Yes opens the page and a calendar invite from info@ arrives within a minute
    • Picking a party size shows "Perfect. We're planning for…"
    • After a refresh, the dashboard shows you as Opened and Attending
    • Tapping Can't make it at the bottom of the page removes the calendar event

    All good? Delete your test row (right-click row 2 → Delete row).

Part F Send to investors

  1. In the Guests tab, paste your investors starting at cell A2:

    • Column A: Name (e.g. Raj Mehta)
    • Column B: Email
    • Column C: Phase (1, 2, 3…)

    From Excel: select those three columns of data (no header row), Ctrl + C, click A2 in the sheet, Ctrl + V. Leave the grey columns empty; the system fills them.

  2. Dashboard → Send invitations → choose Phase 1. It shows how many it found and how many it will send. Click Send and keep the tab open until it says Done.

    Repeat for each phase when you're ready. Nobody is ever sent the invite twice.

  3. After that, it runs itself.

    • Reminder emails go out 7, 3 and 1 day before, to everyone who said Yes or Maybe
    • Bounced emails are marked within the hour
    • 4 or more days after a phase goes out, use Nudge non-responders on the dashboard to follow up once

Part G One request to Jupiter's IT person

  1. This helps keep invitations out of spam. It isn't required to start, but do it this week. Send this message to whoever manages the jupitertexas.com domain (GoDaddy, Google Domains, Cloudflare, etc.):

    Hi, could you add one DNS record to jupitertexas.com? We're sending event invitations from info@ and this helps them reach inboxes. Type: TXT Name / Host: _dmarc Value: v=DMARC1; p=none; rua=mailto:info@jupitertexas.com Thanks!

If something goes wrong

There's no "Anyone" option in step 8

Send this to Jupiter's Google Workspace admin:

Hi, could you allow Apps Script web apps to be shared outside our domain? In the Google Admin console: Apps → Google Workspace → Drive and Docs → Sharing settings → Sharing options → allow users to share outside jupitertexas.com. It's for the holiday party RSVP page. Thanks!
The dashboard says the "API link" or "RSVP page link" is missing or wrong

Check the sheet's Settings tab. B2 must start with https://script.google.com and end with /exec (it's the one from step 8, "Anyone"). B3 must be your Netlify link starting with https://.

I changed something in the code and nothing changed

In Apps Script: Deploy → Manage deployments. For each of the two deployments: click ✏️ → Version: New version → Deploy. The links stay the same.

Tapping a button says "We couldn't save that"

Usually the RSVP link (step 8) was made with "Only myself" instead of "Anyone", or B2 has the dashboard link instead of the RSVP link. Redo step 8 and paste the new link into B2. Then send yourself a new test, because emails already sent keep the old link.

The emails land in Spam

Do Part G (DMARC). Also ask your test recipients to move the email to the inbox and mark it "Not spam"; it helps the next ones.
