Shrink photos

Phone photos are 4–10 MB each and make the website slow. This tool makes every photo in your website folder web-sized (about 200–400 KB). It never deletes or renames a photo: same files, same names, same folders, just lighter. They look the same on screen.

  1. Nothing gets deleted or renamed: each photo is made smaller under its same name, and a copy of every original is kept in a _original-photos folder.
  2. Click the button and choose your dolkar-site folder, the one with index.html inside.
  3. If the browser asks for permission to view and then edit files, click Allow / Save changes.

This browser can't do this. Please open this file in Google Chrome or Microsoft Edge on a laptop or desktop.

    Not part of the website

    These are inside your dolkar-site folder but the website doesn't use them, so they only make the upload bigger. Move them somewhere else (e.g. your Desktop) before uploading to Netlify.

      iPhone photos that websites can't show

      These are in .HEIC format. Websites can't display them. Convert them to JPG (e.g. drop them on squoosh.app, or on iPhone: Settings → Camera → Formats → Most Compatible) and put the JPG back with the same number.

        Heavy PNG photos

        These photos are saved as PNG, a format meant for graphics, so they stay heavy even at the right size. This tool won't change their format (so nothing gets renamed). To make them light yourself: open the photo, save / export it as JPG with the same number (e.g. 02.jpg), then delete the old 02.png. squoosh.app can do this too.
